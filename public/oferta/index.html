O DCF (Fluxo de Caixa Descontado) é o método padrão de profissionais de mercado para estimar o preço justo de uma ação. Usamos WACC calculado via CAPM com dados do BACEN (SELIC, IPCA) e premissas macroeconômicas reais. Os 3 cenários (pessimista, base e otimista) permitem que você entenda o range de valor antes de tomar uma decisão.
